First-run wizard

Builds an observe-mode config: it measures and recommends and never announces. The allowlist stays empty. The result opens in the editor below for review; nothing is written until you save.

    Config editor

    Edits the mounted config file. Saving runs the same checks as a start (loader, environment, every plugin) and reads the file back through the loader. The controller applies it on restart, or on SIGHUP when only bgp.neighbors changed. Needs http.config_editor: true and the admin role.

      Report subscriptions

      Stored reports emailed on a UTC schedule through an smtp notifier. Subscriptions and recipients live in report_subscriptions in the config file. Operators may send one now.
