API tokens

Tokens are for scripts: send one as Authorization: Bearer .... A token has at most the role of the user who made it and follows that user's role. It expires, and it is stored only as a hash. This page uses /api/tokens; the role checks and the audit record are the API's. See docs/auth.md.

API tokens need auth.enabled and a storage plugin in the mounted file (docs/auth.md).

Copy this token now. It is shown once, it is not stored, and it is gone when you close this box or leave the page.
