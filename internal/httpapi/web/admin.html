Users

Users, roles, and passwords go through /api/users (admin role). The role checks, the last-admin lockout, and the audit record are the API's; this page only builds the calls. A user's API tokens are removed with the user. See docs/auth.md.

Users need auth.enabled and a storage plugin in the mounted file (docs/auth.md).
