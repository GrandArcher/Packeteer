## 1. Executive summary

**Overall risk: Moderate. No Critical finding. Two High, seven Medium.**

The core safety rails hold at this commit (section 6 lists what I verified, with lines). The new risk sits in three places the prior audit did not reach:

- **The config editor's program boundary has a hole.** An admin can change the upgrade signing key and release source through the editor, then run any binary via the UI upgrade path (FAB-01). The editor also lets an admin point any `*_env` secret reference at a host they control (FAB-04).
- **The flow collector can be made to allocate gigabytes from one spoofed datagram** (FAB-02). The already-filed "no exporter allowlist" item (#493, SEC-05) is the root cause and deserves a higher priority than Low.
- **The decision engine has one gap in its own rails**: a commit or cost steer that switches to a performance move skips the interface-capacity gate, the flap quarantine, and flip bookkeeping (FAB-03).

**Top 5**

| # | ID | Sev | Summary |
|---|---|---|---|
| 1 | FAB-01 | High | `PUT /api/config` accepts changes to `upgrade.public_key`, `repo`, and `api_url`. After a restart, `POST /api/upgrade/apply` verifies an attacker's release against the attacker's key and executes it. This defeats the documented rule that which programs run is set by the mounted file only. |
| 2 | FAB-02 | High | An IPFIX template set with field count 65535 makes the decoder allocate about 393 KB before it checks the body length, and set parsing continues after the error. One 64 KB spoofed UDP datagram costs about 3 GB of allocation under the decoder lock. No exporter allowlist exists. |
| 3 | FAB-03 | Medium | `policy/commit.go` creates a performance switch off a commit or cost steer without the capacity gate, flap check, or flip bookkeeping that `decide.go` applies to every other performance switch. |
| 4 | FAB-04 | Medium | Any `*_env` key (SNMP community, SNMPv3 auth and priv, SMTP password, OIDC client secret, PagerDuty key) accepts any environment variable name through the editor, so an admin can send `PACKETEER_ADMIN_PASSWORD` in SNMPv2c cleartext to a host they name. Broader than SEC-02 (#489). |
| 5 | FAB-05 | Medium | A third party can make the leak watch withdraw an injected route and hold the prefix out: the RIS Live source accepts any announcement whose path contains the local ASN, and a sighting with `packeteer_community` is a leak regardless of who sent it. Fail-safe in direction, but a remote denial of the controller's core function. |

## 5. Disagreements with the prior audit

- **SEC-06 should be Medium, not Low.** The prior text noted that a shared proxy address "locks everyone out" but filed it under brute-force weakening. With the throttle checked before the session cookie and bearer token (`internal/auth/auth.go:223-227`), an unauthenticated client denies the whole UI and API to every proxied user. See FAB-06.
- **SEC-05 (flow exporter allowlist) should be Medium and move up the batch order.** It was filed as Low with "template table never expires". FAB-02 (3 GB per datagram) and FAB-07 (unbounded rate map) are both reachable only because any address may send flow records; the anomaly detector also turns spoofed counters into mitigation rules (`internal/anomaly/anomaly.go:366-402`, bounded by the RIB check, caps and mode). The allowlist is the one fix that closes all of them.
- **G-01 downgrade to Medium: agree.** The speaker never listens (`internal/rib/rib.go:313-316`), neighbors are configured routers, and the BMP path is bounded by the router allowlist.
- **SAFE-07 kept latent: agree.** The inversion is real (mitigation `Sync` holds `mit.mu` and calls `outbound` -> `ann.mu`; announce `Sync` holds `ann.mu` and calls `Reserved` -> `mit.Holds` -> `mit.mu`), and both run on the one decision goroutine today. The HA step-down path (`ha.go:104` from the elector goroutine) calls `WithdrawAll` on each controller separately and never nests, so it does not change that.
- **"Threat mitigation routes are reported, not withdrawn" on a leak (`docs/leak-watch.md:32`): accepted as a design decision.** I note it because a leaked RTBH route is the worst leak, but a rule is an operator action and the doc says so.
- **PERF-01's size estimate stands; FAB-24 is the bigger cost at scale.** The outcome channel is transient allocation; the eviction loop is CPU time under the engine lock.
