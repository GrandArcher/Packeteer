# Security policy

Packeteer can inject BGP routes, so please report vulnerabilities privately.

Use GitHub's private vulnerability reporting: the **Security** tab of https://github.com/GrandArcher/Packeteer, then **Report a vulnerability**. Do not open a public issue for a vulnerability, and do not include real prefixes, SNMP communities, credentials, or customer data in a report.

Useful details: the version or image tag, the config (redacted), what you expected, and what happened. We aim to acknowledge a report within a few days.

Supported versions: the latest tagged release and `main`. See [docs/THREAT_MODEL.md](docs/THREAT_MODEL.md) for what Packeteer defends against.
